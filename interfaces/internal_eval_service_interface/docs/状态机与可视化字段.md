# 状态机、失败分类与可视化字段说明

## 1. 任务级状态机（`run.status`）

| 状态 | 含义 | 是否终态 |
|---|---|---|
| `queued` | 已创建并在队列中等待调度（受最大并发数保护） | 否 |
| `preparing_questions` | 正在从 `3_dynamic_bench` 抽题并生成下发 JSONL 与 `ab_test` 目录 | 否 |
| `dispatching` | 正在派单给数据拉取适配器 | 否 |
| `running` | 流式执行中（边收 trace、边清洗、边评测、边微批聚类、边对外供数） | 否 |
| `finalizing` | 上游拉取已收敛，正在执行收尾聚类（含自适应建叶）与最终清单同步 | 否 |
| `succeeded` | 全部题目处理完成且 0 失败、0 被拒 | 是 |
| `completed_with_errors` | 任务已收敛，存在部分失败/被拒样本，但其余已就绪结果与对比完整可用（可调用 `/retry-failed` 补跑） | 是 |
| `failed` | 系统级异常或 0 条成功 | 是 |
| `cancelling` | 已收到取消请求，正在安全中止当前评测子进程 | 否 |
| `cancelled` | 已安全中止，已就绪的评测与聚类结果继续保留可查 | 是 |

## 2. 单题单边状态漏斗（`side_cases.status`）

每道题在 `before` 与 `after` 两条线上独立推进：

```text
pending_fetch ──► fetched ──► prepared ──► evaluating ──► evaluated ──► ready (已聚类)
       │             │            │            │              │
       │             └─► rejected │            ├─► ready      └─► failed (cluster)
       │               (准入被拒) │            │  (0问题 GOLD)
       └─► failed (fetch)         └─► failed   └─► failed (eval)
                                     (prepare)
```

前端绘制进度条与漏斗图时，直接读取 `GET /runs/{run_id}` 中的：
- `progress.percent`、`progress.completed_units`、`progress.ready_units`、`progress.paired_ready_cases`、`progress.throughput_per_min`、`progress.eta_seconds`
- `sides_detail.before` / `sides_detail.after` 下的 `total_targets`、`fetched`、`cleaned`、`rejected`、`evaluated`、`gold_pass`、`clustered`、`ready`、`failed`、`failed_by_stage`、`severity_distribution`

## 3. 失败阶段分类（`GET /runs/{run_id}/failures`）

| `stage` | 典型 `error_code` | 说明 |
|---|---|---|
| `fetch` | `COLLECTOR_CASE_FAILED`、`COLLECTOR_MISSING_TRACE`、`FETCH_TIMEOUT`、`UNKNOWN_CASE_KEY`、`INVALID_TRACE_JSON` | 上游拉数失败、超时或回传格式无法配对 |
| `prepare` | `PREPARE_REJECTED`（及 `eval_harness` 准入具体 reason）、`PREPARE_ENGINE_ERROR` | 原始 trace 缺问句/坏行/超限等清洗准入拒绝 |
| `eval` | `EVAL_CASE_FAILED`、`EVAL_NO_OUTPUT`、`EVAL_ENGINE_ERROR` | 归因评测超时、模型调用失败或无有效输出 |
| `cluster` | `CLUSTER_ENGINE_ERROR`、`CLUSTER_ITEM_MISSING` | 增量聚类调用失败或索引缺失 |
| `system` | `PIPELINE_EXCEPTION` | 流水线系统级异常 |

---

## 4. 可视化对比接口字段（`GET /runs/{run_id}/compare`）

- **`before_summary` / `after_summary`**：单边汇总指标（`ready_traces`、`gold_traces`、`pass_rate`、`p0p1_rate`、`avg_problems_per_trace`、`severity_distribution`）。
- **`paired_summary`**：同题配对核心 KPI（`paired_ready_count`、`improved`、`regressed`、`unchanged`、`net_improvement_rate`、`pass_rate_delta`、`p0p1_rate_delta`）。
- **`severity_migration_matrix`**：`before_severity → after_severity` 6×6 迁移计数矩阵（`P0`/`P1`/`P2`/`P3`/`P4`/`GOLD`），可直接渲染桑基图或热力图。
- **`leaf_comparison`**：按影响面排序的问题叶子前后对比（`path`、`stage`、`mechanism`、`name`、`before_traces`、`after_traces`、`delta_traces`）。
- **`stage_mechanism_matrix` & `stage_totals`**：三轴 `S1–S12 × M1–M7` 交叉矩阵（含前后计数与差值），直接支撑热力图可视化。
- **`highlights`**：`improved_examples` 与 `regressed_examples` 典型变化题列表，支持业务方一键下钻查看案例。
