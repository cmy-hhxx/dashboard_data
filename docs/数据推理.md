# TaskManager API 使用指南

面向外部系统对接推理调度：创建数据集 → 复制样板创建任务 → 轮询与恢复 → 拉取会话索引 / judge 明细。

- **Base URL**：`http://<host>:8888/api/v1/task`（内部评测默认 `10.217.216.85:8888`）
- **响应包络**：`{"status_code": 0, "status_msg": "ok", "data": {...}}`；非 0 失败并附 `error_code`。

> **自动化闭环说明**：`internal_eval` 严格按 `version_{YYYYMMDD}_aime_{expert|fast}` 建轮次目录，复制模板 `2740e85cb7b34909` 创建 `AIME_RSI_ABTEST_{YYYYMMDD-HHMMSS}`（`limit=null`）并在 `<round_dir>/<task_id>/` 建异步落盘目录；默认纯 `drop_dir` 消费顶层加工后 `{step}.jsonl`（不读 `raw/` 与 `judge_data`），每 15 分钟自动巡检补缺重试（见 `interfaces/internal_eval_service_interface/docs/拉数同事接口契约.md` §0）。

## 1. 鉴权

除以下 **8 个接口**外均为公开：
`GET /testsets/{id}`、`GET /testsets/{id}/cases`、`POST /tasks/{id}/{start,pause,cancel,reset_failed,fill_missing}`、`POST /engine/*`。

鉴权通过 Header `X-User-Id` / `X-User-Name`（推荐）或 Cookie `user_id` / `user_name` 传入，需在 `[task_manager] allowed_users` 白名单内，否则 `403 FORBIDDEN`。

## 2. 创建数据集

- `POST /testsets`：传 `{"name", "description"?, "cases": [{"case_id"?, "input_list": [{"query": "..."}]}]}`（单轮可简写 `query`，其它字段如 `rubric`/`tags` 原样保留）。单次建议 ≤ 100 条，超出分批调用 `POST /testsets/{id}/append`（按 `case_id` 去重）。表格导入用 `POST /testsets/upload`（`multipart/form-data`）。
- **多模态图片**（必须放在 `input_list[]` 内；case 顶层 `media_url_list` 仅为透传元数据，不参与执行）：

| `fetcher` | 多模态支持 |
|---|---|
| `new` | 完整支持：`image_base64`（推荐，服务端自动转存 GridFS 避免撞 16 MB 文档上限）或内网可达 `public_url` |
| `realtime` | 仅支持同时传 `public_url` + `download_url`（不支持 GridFS `image_ref`） |
| `lumi` / `workbuddy` | 暂不支持图片，仅纯文本 |

## 3. 创建与启动任务（复制样板）

后端无 `copy_task` 接口，标准流程为：**读样板 → 改参数 → 创建 → 启动**。

```bash
H='http://<host>:8888/api/v1/task'; U='X-User-Id: <user>'
PIPE=$(curl -s "$H/tasks/<template_id>" | jq '.data.pipeline')
TASK=$(curl -s -X POST "$H/tasks" -H 'Content-Type: application/json' -H "$U" \
  -d "{\"task_name\":\"run\",\"testset_selections\":[{\"testset_id\":\"$TS\",\"limit\":50}],
       \"concurrency_limit\":2,\"pipeline\":$PIPE}" | jq -r '.data.task_id')
curl -s -X POST "$H/tasks/$TASK/start" -H "$U"
```

- `pipeline.steps[]` 关键字段：`key`、`fetcher`（`realtime`/`new`/`agent`/`lumi`/`workbuddy`）、`is_pre`、`is_deep`、`mode`、`agent_id`、`ab_test_content`、`lumi_profile_id`（`lumi`/`workbuddy` 必填，查 `GET /lumi/profiles/{app_type}`）。
- 测试集推荐用 `testset_selections`（支持逐集 `limit` / `random_seed`）；`pipeline.parallel=true` 并发跑各 step；`concurrency_limit` 控制任务级 case 并发。

## 4. 进度查询与失败恢复

- `GET /tasks/{id}`：`status`（`created`/`running`/`paused`/`completed`/`cancelled`/`failed`），`已完成 = completed_count + partial_count + failed_count`，`active_count` 为实时执行数。
- `GET /tasks/{id}/items?status=partial&page=1&size=50`（`size ≤ 200`）：查 `success_keys` / `missing_keys` / `error`；单条明细走 `GET /tasks/{id}/items/{item_id}`。

| 场景 | 恢复接口 | 行为 |
|---|---|---|
| 日志未就绪（`not_ready`/`no_node`/`network_error`） | `POST /tasks/{id}/retry-recall?max_wait_sec=180` | 直接补抓日志，**免重跑推理** |
| 部分 step 成功（`partial`） | `POST /tasks/{id}/fill_missing` + `start` | **首选**，只补跑 `missing_keys`（已完成任务亦可补齐） |
| 全部 step 失败（`failed`） | `POST /tasks/{id}/reset_failed` + `start` | 整条所有 step 全量重跑 |

## 5. 会话索引与 judge 明细

- **轻量会话索引**：`GET /tasks/{id}/cases?page=1&size=100`，返回各 step 的 `session_id` / `trace_id` / `ts`（供异步 Litefusion 溯源）。
- **拉取 judge 明细**：`GET /tasks/{id}/judge/{key}/download[?page=1&size=100&query=...&testset_id=...]`
  - 返回 `application/gzip` JSONL 流（非 JSON 包络），响应头 `X-Total-Count` 给总数；`page=0`（默认）全量流式下载，`page ≥ 1` 分页（`size ≤ 1000`）。
- **重造 judge**：`POST /tasks/{id}/generate_judge`（从保留的 `result` 重建 `judge_data`）。

## 6. 接口一览

| 用途 | 方法与路径 | 鉴权 |
|---|---|---|
| 数据集建/追/列 | `POST /testsets` · `POST /testsets/{id}/append` · `GET /testsets` | 公开 |
| 数据集详情/cases | `GET /testsets/{id}` · `GET /testsets/{id}/cases` | **需要** |
| 任务建/列/查/改 | `POST /tasks` · `GET /tasks` · `GET /tasks/{id}` · `PUT /tasks/{id}` | 公开 |
| 任务控（启/停/撤） | `POST /tasks/{id}/{start,pause,cancel}` | **需要** |
| 明细与会话索引 | `GET /tasks/{id}/items[/{item_id}]` · `GET /tasks/{id}/cases` | 公开 |
| 恢复（重跑/补缺/补抓） | `POST /tasks/{id}/{reset_failed,fill_missing}`(**需鉴权**) · `POST /tasks/{id}/retry-recall`(公开) | 见左 |
| judge 下载/重造 | `GET /tasks/{id}/judge/{key}/download` · `POST /tasks/{id}/generate_judge` | 公开 |
