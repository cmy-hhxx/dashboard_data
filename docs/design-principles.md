# 界面设计原则

这套原则约束看板的视觉与交互。原则本身与具体页面无关；落到本仓库的数值 token（色阶、圆角、间距、动效时长）见 README 的「设计规则（可复现的 token）」。

## 核心细节

1. **不用生硬边框，改用微对比色阶分层**：放弃传统的实线边框和刺眼的纯黑色，用 1%~3% 的微弱色差来区分层级。
2. **暗色模式下调细字重**：暗色背景下文字容易发虚、产生光晕，需要把字重（粗细）悄悄调细一档，保证阅读清晰度。
3. **等宽数字锁死 + 自适应网格**：防止动态刷新的数字（如倒计时、统计）导致界面抖动，并用自适应网格让排版丝滑展开。
4. **动效要「分性格」**：动效不是千篇一律的——拖拽吸附要瞬间到位（干脆利落），点赞反馈要带 Q 弹回弹（轻快活泼）。
5. **产品只切数据，不分叉卡片样式**：问财与 AIME 共用同一份五卡模板和渲染组件。数据源在适配层转换，归因统一为“版本/模型 → 环节”两列，不额外展示 P0/P1/P2 严重度；指标缺失显示“—”，不切换成另一种布局。
6. **全站不展示操作引导小字**：数据、评测体系与样本三个板块都不添加点击、展开等操作说明、快捷键标记或重复引导；必要动作使用按钮或图标，保留数据标签、状态信息和控件的可访问名称。
7. **数据量与聚类共用完整圆环组件**：统一复用 `hierarchy-card.js` 的 ECharts 旭日图、颜色、中心、图例、尺寸、响应式规则和默认收起状态，不按卡片或产品另写样式。数据量按真实分类层级（可为 2～3 级）展开；聚类按真实树深继续下钻，到叶子停止，不制造额外分类层级。

高级感来源于对「边框、字重、数字对齐、动效节奏」这些人性化维度的把控，避免所有元素都像机器一样生硬运行。

## 高级感的可复现方法

1. **用明确规则定义高级感**：圆角、间距、底色都按可复现的参数执行，让高级感变成一套可复用的方法。
2. **用微差灰度建立层级**：背景与卡片保持约 1% 灰度差，让悬浮感和层次自然出现。
3. **用同心几何统一圆角**：圆角约取短边 ×18%，嵌套元素共享圆心、逐级递减，让界面形成连贯的几何系统。
4. **用间距差完成信息分组**：横向固定 16pt，纵向 16/24pt，外部间距大于或等于内部间距，形成清晰的呼吸节奏。
5. **用统一约束承载受控差异**：Bento 卡片大小可以变化，圆角、间距、色彩规则保持一致，让差异制造节奏、统一制造秩序。
